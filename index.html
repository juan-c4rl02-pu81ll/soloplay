📜 Reglas del Juego

1 La IA solo crea preguntas basándose en el código que scrapea de tu repositorio GitHub.
2 El juego te preguntará si quieres parar después de cada ronda.
3 Después de 5 preguntas del mismo nivel, la IA te preguntará si quieres subir de dificultad.

🚀 ¿Cómo abrir el juego?

Este juego necesita internet. No funciona si lo abrís con doble clic desde tu PC.

✅ Opción recomendada — GitHub Pages (gratis):

  1. Descargá el archivo soloplay_github.html
  2. Subilo a un repositorio en github.com
  3. En Settings del repo → Pages → Source: main branch
  4. Copiá la URL que te da GitHub y compartila con tus compañeros

🖥️ Si tenés VS Code:

Instalá la extensión Live Server → clic derecho en el archivo → Open with Live Server
